# Per-module coverage baseline: <module> <unit> <integration>

# Recorded with go1.27.0, the version CI pins. Coverage percentages move
# between Go releases, so the Makefile forces that toolchain for the coverage
# targets; changing it means changing COVERAGE_TOOLCHAIN, the CI go-version,
# and this file together.
#
# unit        — `go test ./...`, no Docker.
# integration — `go test -tags integration ./...` with docker-compose services up.
#
# Regenerate with: make coverage-update            (unit column)
#                  make coverage-update-integration (both columns; needs Docker)
# Enforced by:     make coverage-check, which reads the unit column and fails
#                  when a module drops more than COVERAGE_TOLERANCE (default 2.0)
#                  points below it.
#
# The gap between the columns is not a gap in testing: fiber, grpc, and s3 keep
# most of their behaviour behind a live server or endpoint, so it is reachable
# only under -tags integration. A number that *falls* is the signal to act on.
